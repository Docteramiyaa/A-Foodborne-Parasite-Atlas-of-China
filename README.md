面向公众的中国食源性寄生虫知识查询网站。按食物、地点、季节和处理方式查清寄生虫风险、健康后果与更安全的做法。

## 你可以做什么

- **按名称查**：输入食物、寄生虫或地区名称，直接进入对应知识。
- **描述情况问**：用自然语言说明“在哪里、什么时候、吃了什么、怎么处理”，获得针对当前情况的回答。
- **按条件探索**：选择地区、四季、食物和做法，查看当前风险、处理是否有效，以及仍缺少的信息。
- **系统浏览**：图鉴按寄生虫、食物与处理方式、地区组织知识；依据页提供可追溯的文献来源。

## 内容说明

- 知识库覆盖 22 种食源性寄生虫、19 类食物与处理方式、34 个省级地区和 66 份来源。
- 风险判断按食物与处理方式区分，避免把“相关寄生虫”直接当成“当前风险”。
- 地区与季节资料保留各自的证据边界；资料未收录不会被表述为“没有风险”。
- 本站用于健康科普，不构成医疗诊断或治疗建议。出现持续或严重症状，请及时就医。
